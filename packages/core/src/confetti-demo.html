🎉 Confetti Toast Demo

Add a celebratory burst when announcing big releases

How it works

Set confetti="true" on <changebot-toast> to fire a confetti burst when the toast appears. Works with any position. The canvas-confetti module is lazy-loaded only when the prop is enabled, so opted-out customers pay zero bundle cost. The burst is also suppressed when prefers-reduced-motion: reduce is set.
